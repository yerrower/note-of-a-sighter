# 完全演绎法

基本上是关于类人脑认知系统的可仿真构建。（仅提供底层框架思路，实际深度仿真需要更多的工程性参数设计，超出本文范畴） 全文整体用从零设计一个智能框架而非还原的思路推进，不会刻意往人脑某个功能上靠，类人脑架构是结果而非目标。

通过从零设计一个认知系统，对知识图谱（非传统，广义）的标准化重塑和标准化推理提供依据，是本项目的最终目的。设计认知系统所产生的类人AI可能，或者哲学或方法论上的影响均属于副产物，并不关心。

预期完整的文档分五部分依次给出：Sighter（观测者）、Operator（执行者）、Deducer（演绎者）、Administrator（管理者）、Seeker（探索者），前三部分以三大功能为切入点，构建认知系统的理论基础，后两部分围绕具体的社会角色将三大功能完整结合，提供应用向的认知框架和一些泛用基础知识图谱的构建。
